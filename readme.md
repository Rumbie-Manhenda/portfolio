# My Portfolio Website

This is my personal portfolio website showcasing information about me, my projects, and my skills. The website is built using vanilla CSS, HTML, and JavaScript.

The creation of this portfolio served as a learning experience, allowing me to enhance my skills in building websites with these languages. It provided an opportunity to explore and practice various web development techniques.

For the backend, I utilized Node.js with Express.js and a MySQL database. This combination enabled me to handle server-side logic and data management efficiently.

The website aims to provide visitors with an overview of my background, achievements, and capabilities. It serves as a central hub for potential employers, clients, or collaborators to learn more about me and my work.

## Dependencies

- Node.js
- Express.js
- MySQL
